# Common Vietnamese errors in academic writing

Grammar, word choice and spelling errors that appear in theses and papers regardless of field. Check these in every polishing pass.

## 1. Sentence structure
| Error | Example (wrong) | Fix |
|---|---|---|
| Adverbial phrase used as subject (missing subject) | Qua kết quả khảo sát cho thấy 70% người dùng… | Kết quả khảo sát cho thấy… / Qua khảo sát, học viên nhận thấy… |
| Same, with "trong" | Trong chương này trình bày kiến trúc hệ thống. | Chương này trình bày kiến trúc hệ thống. |
| Same, with "với" | Với sự phát triển của AI đã tạo ra nhiều cơ hội. | Sự phát triển của AI tạo ra nhiều cơ hội. |
| Same, with "bằng" | Bằng phương pháp X đã giúp giảm độ trễ. | Phương pháp X giúp giảm độ trễ. |
| Missing predicate (long noun phrase only) | Hệ thống quản lý tài liệu dùng chung cho các phòng ban với khả năng tìm kiếm theo ngữ nghĩa. | Add the verb: "Đề án xây dựng hệ thống…" |
| Comma between subject and predicate | Mô hình được đề xuất trong chương này, đạt độ chính xác 0,82. | Remove the comma. |
| Mismatched paired connectors | Tuy hệ thống chạy nhanh nhưng mà vẫn… / Vì… nên do đó… | Tuy… nhưng…; Vì… nên… (one pair, no extra) |
| Dangling "nhằm" | Nhằm nâng cao chất lượng, các giải pháp sau. | Nhằm nâng cao chất lượng, đề án đề xuất các giải pháp sau. |
| Run-on sentence joined by commas | (5 clauses joined by commas) | Split; use "do đó", "trong khi đó"… |
| List items not parallel | thu thập dữ liệu, việc làm sạch, nhãn được gán | thu thập, làm sạch, gán nhãn dữ liệu |

## 2. Redundancy (thừa từ)
| Redundant | Use |
|---|---|
| các những, những các | các / những |
| tất cả mọi | tất cả / mọi |
| rất là, khá là, hơi bị | rất / (drop) |
| mục đích là nhằm | nhằm / mục đích là |
| lý do là vì | vì / lý do là |
| đầu tiên trước hết | trước hết |
| quá trình tiến trình | quá trình |
| tiến hành thực hiện | thực hiện / tiến hành (+ object) |
| cùng chung | chung / cùng |
| hoàn toàn tuyệt đối | hoàn toàn |
| tái lặp lại | lặp lại |
| giao nhiệm vụ cho… đảm nhận nhiệm vụ | (pick one verb) |
| có thể có khả năng | có thể |
| được thực hiện bởi việc | (rewrite actively) |

## 3. Confusable words (dùng nhầm từ)
| Often confused | Meaning / correct use |
|---|---|
| yếu điểm vs điểm yếu | yếu điểm = điểm quan trọng (key point); điểm yếu = weakness |
| giả thuyết vs giả thiết | giả thuyết = hypothesis (to be tested); giả thiết = assumption, premise (taken as given) |
| phương pháp / phương thức / phương án | method / mode, manner / option, plan |
| hoàn thiện vs hoàn chỉnh | hoàn thiện = improve toward perfection (process); hoàn chỉnh = complete (state) |
| cấp thiết vs cấp bách | cấp thiết = necessary and urgent (rationale "tính cấp thiết"); cấp bách = pressing, emergency |
| tác động vs ảnh hưởng | tác động = act upon (often direct, causal); ảnh hưởng = influence (broader) |
| đánh giá vs nhận định | đánh giá = evaluate (with criteria); nhận định = judge, comment |
| thực hiện vs tiến hành | thực hiện = carry out (a task, plan); tiến hành = conduct (an activity, experiment) |
| kiểm tra / kiểm định / kiểm thử / kiểm chứng | check / statistical test, accreditation / software testing / verify against evidence |
| hiệu quả / hiệu suất / hiệu năng | effectiveness / efficiency (ratio) / performance (speed, resources) |
| chính xác / chuẩn xác | accurate (accuracy) / precise (Precision) |
| bảo mật vs an ninh vs an toàn | security (of data) / security (national, public) / safety |
| linh hoạt vs linh động | flexible (plans, design) / mobile, adaptive (people, actions); "linh hoạt" for systems |
| khuyến nghị / kiến nghị / đề xuất | recommend (advice) / petition, recommend to authorities / propose |
| nguyên nhân vs nguyên do | cause / reason (more colloquial) |
| tham khảo vs tham chiếu | consult (sources) / refer to, cross-reference |

## 4. Spelling traps (chính tả)
| Wrong | Right |
|---|---|
| sát nhập | sáp nhập |
| chuẩn đoán | chẩn đoán |
| sáng lạn | xán lạn |
| bàng quang (thờ ơ) | bàng quan (bàng quang = bladder) |
| thăm quan | tham quan |
| xử dụng | sử dụng |
| đề suất | đề xuất |
| xác xuất | xác suất |
| năng xuất | năng suất |
| hiệu xuất | hiệu suất |
| tần xuất | tần suất |
| sơ xuất | sơ suất |
| chặc chẽ | chặt chẽ |
| trau giồi | trau dồi |
| cọ sát | cọ xát |
| chia sẽ | chia sẻ |
| dành giải / giành thời gian | giành giải / dành thời gian |
| khuyến khít | khuyến khích |
| bức xúc → used for "urgent" | cấp bách (bức xúc = frustrated) |

| giám sát / dám sát | giám sát |

Rule of thumb: "xuất" = out/produce (xuất bản, sản xuất, đề xuất, truy xuất, xuất hiện); "suất" = rate/share (năng suất, hiệu suất, tần suất, xác suất, lãi suất, công suất).

## 5. Register: Sino-Vietnamese vs native words
- Academic text uses Sino-Vietnamese terms where they are standard (phân tích, đánh giá, giả thuyết), but do not stack them: "tiến hành thực hiện việc triển khai áp dụng" → "triển khai".
- Prefer the shorter precise word: "sử dụng" or "dùng" (both fine; pick by rhythm, not by formality alone); "nhằm mục đích" → "nhằm" / "để".
- Avoid literary or bureaucratic flourishes: "hết sức", "vô cùng", "một cách sâu sắc", "nhằm góp phần thiết thực vào".
- Avoid spoken forms: "cái", "thằng", "mấy", "chạy ngon", "ổn áp", "xịn".

## 6. Punctuation and spacing
- No space before , . ; : ? ! ) ; one space after. Space before "(" and after ")".
- Vietnamese quotation marks “ ”; no space inside.
- Ellipsis "…" only in quotes; avoid "v.v." in academic lists (state the full list or "như A, B").
- Dash for ranges "1–5" (en dash), not hyphen.
- Do not put a colon right after a verb that takes a direct object unless a list follows.

## 7. Spelling standard: tone marks and i/y
No binding national spelling rule applies to theses. Pick one style, apply it everywhere, and follow the school template if it states one.
- Reference standard: Quyết định 1989/QĐ-BGDĐT (25/5/2018), "Quy định về chính tả trong chương trình, sách giáo khoa giáo dục phổ thông" (scope: school textbooks; a defensible default).
  - Tone mark (Điều 8): when the main vowel is a single letter, the mark goes on it: hoà, quý hoá, thuỷ, khoẻ (the "old" placement); for ia, ua, ưa on the first letter (bìa, lụa, lửa); for iê, yê, uô, ươ on the second (biển, thuyền, nhuộm, được).
  - i/y (Điều 9): after an initial consonant with no glide and no final consonant, write i: kĩ, lí, mĩ, tỉ lệ, bác sĩ, hi vọng. Proper names keep their own spelling (Nguyễn Vỹ).
  - Decimals with a comma (Điều 11).
- The "new" placement (hòa, thủy, khỏe) and y-forms (kỹ, lý) are widespread in print and also acceptable if used consistently.
- Do not mix: grep for both forms (`hoà|hòa`, `thuỷ|thủy`, `kĩ|kỹ`, `lí |lý `) before submission.
- Capitalization of organisations, place names, titles, documents: Nghị định 30/2020/NĐ-CP, Phụ lục II (for administrative documents; reference only): "Bộ Giáo dục và Đào tạo", "thành phố Đà Nẵng" but "Thành phố Hồ Chí Minh", "Thủ tướng Chính phủ", "Bộ luật Dân sự", "Nhà nước", "Nhân dân"; titles of books and journals capitalize only the first syllable (and proper names).
