# Citations and references (quick reminder)

The full guidance (IEEE, APA 7, Harvard, Vancouver, Vietnamese conventions, BibTeX/biblatex, web/software/AI/dataset sources, reference-list audit) lives in the `trich-dan-tai-lieu` skill. Read that skill for any real citation work. Essentials:

- Cite only sources you have actually opened (original page, DOI, arXiv, live URL). If you could read only the abstract, write only what the abstract allows.
- Every claim that is not the writer's own needs a source; another party's numbers are cited in the same sentence.
- Paraphrase in your own words and still cite; verbatim quotes go in quotation marks with a page number if available.
- Keep one citation style for the whole document; every reference-list entry is cited at least once and vice versa; use consistent title capitalization (sentence case in IEEE/APA).
