# Structure by document type

Always check the school's/journal's formatting template and regulations first; what follows is a general frame.

## 1. Thesis, project report, undergraduate thesis
| Part | Content | Style note |
|---|---|---|
| Tóm tắt (Vietnamese, English) | context 1–2 sentences, problem, solution, data/experiments, results in numbers, limitation in 1 sentence | 250–400 words; no citations; no unusual abbreviations |
| Mở đầu / Chapter 1 | reason for the topic, objectives (general, specific, measurable), research questions, subject, scope, method, contributions, outline | objectives must match what the experiment chapter measures |
| Tổng quan (literature review) | related directions along an axis (time or theme), comparison table, gap | do not list papers one by one; one direction per paragraph, ending with the difference from this work |
| Cơ sở lý thuyết | concepts and formulas used in the work | each concept ends with where it is used; do not copy a textbook |
| Phân tích, thiết kế | current state, requirements, use cases, architecture, data | write only what has a source; survey figures must be real |
| Triển khai | technology, main flows, configuration, testing | describe what was done, do not advertise technology |
| Thực nghiệm, đánh giá | evaluation questions, data, configuration, metrics, results, analysis, qualitative examples, **limitations** | the full limitations section lives here |
| Kết luận, kiến nghị | check each objective: met / partly met / not measured; contributions; limitations; future work; recommendations | add no new results; do not repeat earlier chapters verbatim |

Chapter opening: 2–3 sentences saying what the chapter does. Chapter ending: 2–4 sentences saying what the chapter established and bridging to the next chapter.

## 2. Paper (IMRaD)
| Part | Content |
|---|---|
| Title | specific, containing the subject and method; no "Nghiên cứu về…", no self-praise |
| Abstract | 150–250 words: problem, method, data, main result in numbers, significance |
| Introduction | short context → gap → contributions (list 2–4 points) → outline |
| Related work | grouped by direction, compared with this paper |
| Method | enough for others to reproduce |
| Experiments, results | setup, baselines, tables, tests if any |
| Discussion | interpret results, limitations, threats to validity |
| Conclusion | 1 paragraph: what was done, results, next steps |

## 3. Technical report, proposal
- Proposal (đề cương): objectives, contents, methods, plan, expected products; verbs in the future tense ("sẽ xây dựng"), no claims of results.
- Technical report: purpose, scope, description, results, open issues; short sentences, more tables than prose.

## 4. Abstract: 6-sentence frame
1. Context and problem.
2. The specific gap or challenge.
3. Proposed solution (what it is, its main components).
4. Data and how it was evaluated.
5. Main result in numbers.
6. Limitation or significance (one sentence).
Add 4–6 keywords.
