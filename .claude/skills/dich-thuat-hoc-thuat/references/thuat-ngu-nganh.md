# Field terminology (English ↔ Vietnamese)

Common Vietnamese renderings in academic use. Before fixing a term, confirm it in 3–5 recent Vietnamese papers/theses of the same field; schools and sub-fields differ. Computing terms (keep vs translate) are in `van-phong-hoc-thuat/references/thuat-ngu.md`.

Watch the words whose translation changes with the field: *leverage* (tận dụng; finance: đòn bẩy), *performance* (hiệu năng; business: kết quả hoạt động), *validity* (tính hợp lệ; social science: độ giá trị / giá trị thang đo), *significant* (có ý nghĩa thống kê; otherwise quan trọng), *subject* (đối tượng; medicine: người tham gia), *treatment* (điều trị; experiment: can thiệp/nghiệm thức).

|---|---|

| standard deviation / variance | độ lệch chuẩn / phương sai |
| standard error | sai số chuẩn |
| confidence interval | khoảng tin cậy |
| p-value / significance level | giá trị p / mức ý nghĩa |
| statistically significant | có ý nghĩa thống kê |
| effect size | cỡ hiệu ứng, độ lớn ảnh hưởng |
| correlation / regression | tương quan / hồi quy |
| coefficient | hệ số |
| independent / dependent / control variable | biến độc lập / biến phụ thuộc / biến kiểm soát |
| moderator / mediator | biến điều tiết / biến trung gian |
| latent variable, construct | biến tiềm ẩn, khái niệm nghiên cứu |
| observed variable, item | biến quan sát |

| validity (convergent / discriminant) | giá trị (hội tụ / phân biệt) |

| sample / sample size / sampling | mẫu / cỡ mẫu / chọn mẫu |

| population | tổng thể |

| cross-sectional / longitudinal / panel data | dữ liệu chéo (cắt ngang) / dữ liệu theo thời gian (dọc) / dữ liệu bảng |
| time series | chuỗi thời gian |
| questionnaire / survey | bảng hỏi / khảo sát |
| Likert scale | thang đo Likert |
| qualitative / quantitative / mixed methods | định tính / định lượng / phương pháp hỗn hợp |

| case study | nghiên cứu trường hợp (tình huống) |

| theoretical / conceptual framework | khung lý thuyết / khung khái niệm |
| research gap | khoảng trống nghiên cứu |
| research question / objective | câu hỏi nghiên cứu / mục tiêu nghiên cứu |
| finding | phát hiện, kết quả |
| implication (managerial / policy) | hàm ý (quản trị / chính sách) |
| empirical study | nghiên cứu thực nghiệm (economics: thực chứng) |
| robustness check | kiểm định độ vững |
| inter-rater agreement | độ đồng thuận giữa người chấm |

| competitive advantage | lợi thế cạnh tranh |
