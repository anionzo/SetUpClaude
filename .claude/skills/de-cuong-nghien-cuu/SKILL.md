# Research proposal (đề cương, thuyết minh đề tài)

The school's or funder's form is authoritative: use its headings in its order. Typical Vietnamese master's templates (checked 2026-11-13 across several universities; no single national template) contain the sections in §2. Related: `tong-quan-tai-lieu` (review and gap), `van-phong-hoc-thuat` (style), `trich-dan-tai-lieu`, `trinh-bay-van-ban-hoc-thuat` (luận văn vs đề án, Thông tư 23/2021).

## 1. Topic and title
- Topic = problem + context + approach. Narrow until it fits the time (master's: one semester to a year) and data you can actually access.
- Check feasibility before writing: data/access permission, tools, supervisor's expertise, ethical approval if human subjects.
- Đề án (applied track) must target a real problem at a real unit and propose and verify a solution; luận văn (research track) must answer a research question with an academic contribution.
- Title: specific noun phrase naming object, method/solution and context; no "Nghiên cứu một số vấn đề…", no unexplained acronyms; usually ≤ 25 words. Example pattern: "<Giải pháp/Mô hình> <làm gì> cho <đối tượng> tại <bối cảnh>".

## 2. Sections and what each must do
| Section | Content | Common faults |
|---|---|---|
| Tính cấp thiết (lý do chọn đề tài) | the practical and/or theoretical problem with evidence (numbers, cases, documents), why now, who benefits | generic opening about "cách mạng 4.0", no evidence |
| Tổng quan tình hình nghiên cứu | domestic and international work grouped by approach; what is solved, what remains; the gap this work fills | listing papers one by one; no gap; outdated sources |
| Mục tiêu (tổng quát, cụ thể) | 1 overall + 2–4 specific, each verifiable (verb + object + criterion) | "tìm hiểu", "nghiên cứu" as objectives; unmeasurable |
| Câu hỏi / giả thuyết nghiên cứu | questions answerable by the method; hypotheses testable (research track) | questions not matching objectives |
| Đối tượng, phạm vi | object of study; scope by content, space (unit), time, data | scope too broad; no time frame |
| Phương pháp nghiên cứu | design, data sources and collection, sample and its justification, tools, analysis/evaluation methods, metrics and baselines | naming methods without saying how they are applied ("phương pháp phân tích, tổng hợp") |
| Ý nghĩa khoa học và thực tiễn | concrete expected contribution | inflated claims |
| Nội dung dự kiến (bố cục) | chapter/section outline | outline not aligned with objectives |
| Kế hoạch thực hiện | timeline by task with deliverables (Gantt-style table) | unrealistic, no buffer |
| Tài liệu tham khảo | sources actually cited, verified, current | unverified or uncited items |

Alignment test: every specific objective → has a question → has a method → has a chapter → has an evaluation criterion. Draw this as a table and fix gaps.

## 3. Writing objectives
- Use action verbs with outputs: "xây dựng…", "đề xuất…", "đánh giá … theo tiêu chí …", "so sánh … với …".
- Each objective has a success criterion or a measured outcome (even if the target value is not fixed).
- Avoid "tìm hiểu", "nghiên cứu về", "góp phần" as objectives.

## 4. Grant proposals (thuyết minh đề tài; NAFOSTED and similar)
NAFOSTED basic research uses its own forms (application, proposal, CV forms; current versions on the fund's site and vbpl.vn) [section list of the proposal form unverified]. Generic structure expected by most funders:
1. Significance and state of the art (with gap).
2. Aims/objectives and research questions.
3. Approach and methods per work package; risks and alternatives.
4. Expected outputs (publications with target venue level, software, datasets, training of students), measurable.
5. Team and qualifications; roles; collaboration.
6. Timeline and milestones.
7. Budget with justification per item, following the funder's cost rules.
8. Ethics, data management, intellectual property.
Reviewers score novelty, feasibility, team capacity, output credibility and budget fit; write so each criterion is easy to find.

## 5. Before submitting

- [ ] Objective–question–method–chapter–evaluation alignment table has no empty cells.
- [ ] Data access and ethics confirmed.
- [ ] Timeline realistic; supervisor agrees.
- [ ] References verified (`tim-va-kiem-nguon`); style consistent (`trich-dan-tai-lieu`).
